# Student Management System

A simple Student Management System built using React.js.

## 🚀 Live Demo
https://yashas-student-management.netlify.app

## 📌 Features
- Add Student
- Edit Student
- Delete Student
- Search Student
- Loading Animation
- Responsive UI

## 🛠 Technologies Used
- React.js
- JavaScript (ES6)
- HTML5
- CSS3

## 📂 Project Structure
src/
components/
StudentForm.js
StudentTable.js
Loading.js
data.js
App.js

## 📖 Description
This project allows users to manage student records using a simple and interactive interface. Users can perform CRUD operations such as adding, editing, deleting, and searching student records. All operations are handled on the frontend using React state.
